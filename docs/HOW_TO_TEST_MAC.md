# HOW TO TEST ON MAC — Dark World

## 1. Instalar Godot 4.x
https://godotengine.org/download/macos/
Baixar versão Standard (não .NET/C#)

## 2. Baixar o projeto
https://zorionlabs.net/dark/downloads/DarkWorld-Mac.zip
Ou via scp: scp -r root@5.78.142.138:/opt/darkworld/godot-client/ ~/Projects/darkworld/

## 3. Abrir no Godot
- Descompactar o zip
- Abrir Godot → Import → Selecionar pasta
- Ou: File → Open → project.godot

## 4. Ignorar Gatekeeper
Se macOS bloquear: System Preferences → Security → Allow Anyway

## 5. Executar (F5)
A tela inicial DARK WORLD aparece

## 6. Criar usuário
Clicar "CRIAR USUARIO TESTE"

## 7. Entrar no mundo
Clicar "ENTRAR NO MUNDO"

## 8. Controles
- WASD: Mover
- K: Matar personagem
- R: Retornar dos mortos

## 9. Verificar
- Dragão vermelho ao longe
- Território verde no centro
- Mundo Congelado após morte
