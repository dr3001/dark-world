# MVP SCOPE — Dark World

## O que ESTÁ no MVP

- [x] Servidor dedicado configurado
- [x] PostgreSQL + Redis + Nakama rodando
- [x] World Engine estruturado
- [x] Schema de banco completo (18 tabelas)
- [x] Seeds com 3 mundos, 5 territórios, 3 facções, 1 dragão
- [x] Backup automático diário
- [x] Documentação completa (15+ docs)
- [ ] Entity System funcional
- [ ] Event Engine funcional
- [ ] DeathModule
- [ ] AfterlifeModule
- [ ] 2 jogadores conectam via Nakama
- [ ] Personagem morre e vai para Mundo dos Mortos
- [ ] Personagem retorna após timer/admin
- [ ] Dragão spawna e ataca território
- [ ] Tudo registrado em audit_logs

## O que NÃO está no MVP

- Combate real (só estrutura de evento)
- Economia (ouro, itens, comércio)
- Godot client completo (só projeto vazio)
- Admin Panel funcional
- Múltiplos dragões
- Sistema político avançado
- Castelos e cidades
- Dinastia / herança
- Sistema adulto
- Mobile / Steam
- Anticheat pago
- Marketplace
- Muitos mundos paralelos

## Critério de Sucesso do MVP

Pai e filho entram no mesmo mundo.
Um personagem morre.
Vai para o Mundo dos Mortos.
Retorna.
Tudo fica registrado no servidor.
