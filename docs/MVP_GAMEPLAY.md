# MVP GAMEPLAY — Dark World

## Objetivo do MVP
Pai e filho entram no mesmo mundo. Um morre, vai para o Mundo Congelado, depois retorna. Dragão existe. Tudo registrado.

## Funcionalidades MVP
- [x] Criar conta (Nakama)
- [x] Criar personagem (World Engine)
- [x] Mover personagem (placeholder)
- [x] Morrer (evento CHARACTER_DIED)
- [x] Ir para afterlife (AFTERLIFE_ENTERED)
- [x] Retornar (AFTERLIFE_RETURNED)
- [x] Dragão existe (DRAGON_SPAWNED)
- [ ] Godot Client
- [ ] Combate real

## Fora do MVP
Combate, economia, política, castelos, marketplace, sistema adulto, mobile.
