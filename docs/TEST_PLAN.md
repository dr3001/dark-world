# TEST PLAN — Mission 5.1

## Objetivo
Validar que Rogerio consegue abrir e executar o projeto no Mac.

## Pré-requisitos
- [ ] Godot 4.x instalado no Mac
- [ ] DarkWorld-Mac.zip baixado
- [ ] Conexão com internet (servidor 5.78.142.138)

## Passos

| # | Passo | Comando/Ação | Resultado Esperado |
|---|-------|-------------|-------------------|
| 1 | Abrir Godot | Clicar Godot.app | Editor abre |
| 2 | Importar projeto | File→Open→project.godot | Projeto carrega |
| 3 | Executar | F5 | Tela DARK WORLD aparece |
| 4 | Criar usuário | Clicar CRIAR USUARIO TESTE | Status: Conta criada |
| 5 | Entrar no mundo | Clicar ENTRAR NO MUNDO | Cena World carrega |
| 6 | Ver dragão | Olhar para posição (20,20) | Cubo vermelho visível |
| 7 | Ver território | Olhar para centro | Plano verde visível |
| 8 | Andar | WASD | Personagem move |
| 9 | Morrer | Pressionar K | Vai para Mundo Congelado |
| 10 | Retornar | Pressionar R | Volta ao Vale Cinzento |
