# Dark World — Ranking API Contracts
## GET /rankings/global → {rankings: [{user_id,display_name,ranking_type,score,rank_position}]}
## GET /rankings/season → {rankings[], season: {id,name,starts_at,ends_at,status}}
## GET /rankings/clans → {rankings: [{name,tag,member_count,level}]}
## Ranking types: xp, level, zorium, quests, playtime, events, clan, season
## Score types: quest, event, combat, exploration, participation, clan
