# Dark World — Event System
## Tipos: seasonal, invasion, festival, anniversary, special
## Eventos seed: Halloween, Natal, Ano Novo, Pascoa, Festival do Vale, Invasao de Vorak, Aniversario
## Cada evento: starts_at, ends_at, status (scheduled/active/ended/cancelled), rewards, ranking_enabled, shop_items_enabled
## Tabelas: game_events, event_rewards, event_items, scheduled_maintenance, server_announcements
## API: GET /events/active, GET /events/calendar
## Calendario: combina events + maintenance + announcements
